# Pharma Drug Sales Analysis & Demand Forecasting 

## 1. Overview

The Pharma Drug Sales Analysis & Demand Forecasting project combines Power BI analytics and machine learning techniques to analyze pharmaceutical sales performance and support business decision-making.

The project includes:
- Interactive Power BI dashboard for sales analytics
- KPI tracking and business intelligence reporting
- Sales trend analysis across multiple drug categories
- Machine learning models for demand forecasting using Python

This project demonstrates practical skills in:
- Data Analytics
- Power BI Dashboard Development
- Data Visualization
- Machine Learning
- Demand Forecasting
- Business Intelligence
